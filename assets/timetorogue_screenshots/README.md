# Time to Rogue website screenshots

Updated for the 1.2.0 release on September 11, 2026. These are native simulator
captures from the game's approved release screenshot work, not mockups.
The local source folders were named 1.3 before the release was numbered 1.2.0.

Current gallery:

- `iphone_gameplay.png`, `iphone_low_focus.png`, `iphone_perks.png`: the raw
  iPhone captures numbered 01, 02, and 03 in the game's `screenshots/app-store-1.3/raw/iphone-6.9-inch/`.
- `01_gameplay.png`, `02_close_call.png`, `03_death.png`, `04_guardian.png`,
  `05_deep_floor.png`: the five approved Watch captures, in order, from
  `screenshots/time-to-rogue-1.3-gameplay-screenshots/watch-ultra-49mm/`.

All current gallery images use the default Dead Signal theme and emphasize the
game, not paid cosmetics. Older images remain here for historical reuse but are
not referenced by the current gallery.
